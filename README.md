## Shortcut Key

### 1. 系统与服务

| 快捷键 | 操作 |
|---|---|
| `⌃⌥⌘Y` | 重启 Yabai 服务 |
| `⌃⌥⌘S` | 重启 skhd 服务 |
| `⌃⌥⌘T` | 占位操作（当前为 `true`，无实际效果） |
| `⌃⌥⌘R` | 同时重启 Yabai 与 skhd |

### 2. 窗口管理（Yabai）

#### 聚焦与移动

| 快捷键 | 操作 |
|---|---|
| `⌃⌘H` / `⌃⌘J` / `⌃⌘K` / `⌃⌘L` | 分别聚焦左 / 下 / 上 / 右侧窗口 |
| `⌃⌥H` / `⌃⌥J` / `⌃⌥K` / `⌃⌥L` | 平铺窗口：与左 / 下 / 上 / 右窗口交换位置；浮动窗口：移动到相应半屏位置 |
| `⌃⌥1` … `⌃⌥9` | 将当前窗口移动到空间 1 … 9 |
| `⌃⌥0` | 将当前窗口移动到空间 10 |
| `⌥⌘Tab` | 将当前窗口移动到下一台显示器；到末尾时循环到上一台，并聚焦该窗口 |

#### 调整尺寸与布局

| 快捷键 | 操作 |
|---|---|
| `⌃⌥↓` | 向下扩大窗口 100 px；必要时改为向下侧边界调整 |
| `⌃⌥←` | 向左缩小窗口 100 px |
| `⌃⌥→` | 向右扩大窗口 100 px |
| `⌃⌥↑` | 向上扩大窗口 100 px |
| `⌃⌥Return` | 近似最大化：占当前显示器 `90% × 90%`，保留边距 |
| `⌃⌥X` | 将当前窗口居中 |
| `⌃⌥F` | 浮动窗口：铺满显示器；平铺窗口：切换 Yabai 全屏缩放 |
| `⌃⌥R` | 轮换当前空间中的窗口顺序 |
| `⌃⌥E` | 均分当前空间中所有平铺窗口 |
| `⌃⌥O` | 切换当前窗口节点的横向 / 纵向分割方向 |
| `⌃⌥T` | 切换浮动状态；切换为浮动后自动居中 |
| `⌃⌥=` | 当前窗口宽、高各增加 50 px（配置中为物理键码 `0x18`） |
| `⌃⌥-` | 当前窗口宽、高各减少 50 px（配置中为物理键码 `0x1B`） |

### 3. 应用启动

| 快捷键 | 操作 |
|---|---|
| `⌥T` | 打开 Ghostty |
| `⌃⇧M` | 打开 Music |
| `⌥W` | 打开 WeChat |
| `⌥F` | 打开 Finder |

### 4. 鼠标窗口操作（Yabai）

| 手势 | 操作 |
|---|---|
| `⌥` + 左键拖拽 | 移动窗口 |
| `⌥` + 右键拖拽 | 调整窗口大小 |
| 将窗口拖放到另一个平铺窗口上 | 交换两个窗口的位置 |

### 5. Ghostty：分屏、标签页与配置

#### 常用默认操作（macOS）

| 快捷键 / 入口 | 操作 |
|---|---|
| `⌘D` | 在右侧新建分屏 |
| `⇧⌘D` | 在下方新建分屏 |
| `⌘⌥←` / `⌘⌥↓` / `⌘⌥↑` / `⌘⌥→` | 聚焦左 / 下 / 上 / 右侧分屏 |
| `⌘[` / `⌘]` | 切换到上一个 / 下一个分屏（按创建顺序） |
| `⌃⌘←` / `⌃⌘↓` / `⌃⌘↑` / `⌃⌘→` | 向相应方向调整当前分屏边界，每次 10 px |
| `⇧⌘Return` | 临时放大当前分屏；再次按下恢复布局 |
| `⌃⌘=` | 均分当前标签页中的分屏尺寸 |
| `⌘W` | 关闭当前 surface（通常即当前分屏；没有分屏时可能关闭标签页/窗口） |
| `⌘T` | 新建标签页 |
| `⇧⌘P` | 打开命令面板；可搜索分屏、关闭、缩放、均分等操作 |
| `⇧⌘,` | 重新加载 Ghostty 配置 |
